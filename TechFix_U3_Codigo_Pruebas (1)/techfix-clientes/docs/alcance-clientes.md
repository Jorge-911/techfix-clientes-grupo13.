# Alcance de Gestión de clientes

Avance 2 de Ingeniería de Software. Continúa la elección Python + Django del Avance 1.

- RF-01: registrar identificación, nombres, teléfono, correo y dirección.
- RF-18 parcial: modificar datos de clientes con autorización.
- Funciones de apoyo: listado y búsqueda por nombre o identificación.
- No incluye: equipos, reparaciones, inventario, ventas ni eliminación de clientes.

## Preparación de los siguientes avances
Avance 3: planificar pruebas unitarias de validación, integración con base de datos y aceptación por usuario.
Avance 4: implementar las funciones, automatizar pruebas y añadir su ejecución al CI.

Esta rama agrega la definición del alcance y servirá para abrir el primer PR hacia main. No fusionarla localmente antes de abrir el PR remoto.
